# resolution: video analyzer

[![CI/CD](https://badgen.net/github/checks/mcandre/resolution?icon=github)](https://github.com/mcandre/resolution/actions) [![License](https://badgen.net/static/license/BSD/ab2b29?icon=freebsd)](LICENSE.md)

# SUMMARY

resolution queries video files.

# EXAMPLE

```console
$ resolution video.mp4
1280x720
```

# DOWNLOAD

```sh
git clone https://github.com/mcandre/resolution.git ~/src/github.com/mcandre/resolution
```

* [bash](https://www.gnu.org/software/bash/) 4+
* [ffmpeg](https://www.ffmpeg.org/)
* [git](https://git-scm.com/)

Register `"$HOME/src/github.com/mcandre/resolution/bin` to `PATH` environment variable.
